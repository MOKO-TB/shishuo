# 师说桌宠「小知」形象提示词

> 用途：发给图像生成 AI（豆包 / 即梦 / 通义万相 / Midjourney / SD）出概念效果图。
> 品牌底色：暖纸 `#F4F0E6`、墨绿 `#146C56`、深墨 `#14211B`、米白 `#F6F1E5`、金 `#D8A52A`。

## 一、角色设定卡

| 项 | 设定 |
| --- | --- |
| 名字 | 小知（昵称「知知」） |
| 物种 | 拟人化知了（蝉）精灵，不是写实昆虫 |
| 性格 | 温和、爱点头、听到问题会「知了知了」地应；上课会打瞌睡，老师回复时立刻精神 |
| 体型 | Q 版 2.5 头身，圆滚滚，两只小手两只小脚 |
| 主色 | 头与背墨绿 `#146C56`，脸与肚皮米白 `#F6F1E5`，眼睛深墨 `#14211B`，额头一颗金点 `#D8A52A` |
| 翅膀 | 一对半透明浅玉色翅膀，质感像宣纸 / 磨砂玻璃 |
| 随身物 | 怀里抱一枚米白色、对话气泡形状的小书签（**上面不要有字**） |

### 品牌映射（讲给评委 / 用户听的故事）

- **知了 = 知道了 / 会了**：答疑产品最想要的那句反馈。
- **双翼 = 双通道**：一片翅膀是 AI 秒答，一片是老师精答。
- **蝉蜕 = 答案留下来**：老师答过的题沉淀成 FAQ，像蝉蜕一样留在树上。
- **额头金点 = 老师兜底**：呼应 logo 右下角那颗金点。
- **夏天梧桐 = 校园**：蝉声是大学夏天最共同的记忆。

## 十、使用建议

1. **先只出提示词 1**，挑一张三视图定稿；不要一上来就生成场景图。
2. 定稿后把这张图作为**垫图 / 参考图**（MJ 用 `--sref` 或图片参考，SD 用 IP-Adapter / ControlNet），再生成表情、动作、场景，形象才不跑偏。
3. 生成时**不要让它画字**，AI 写中文必糊；slogan、按钮文案后期在 Figma / PS 里加。
4. 桌宠落地尺寸建议：常驻形象 256–512px 透明 PNG；像素版 64px；先做「待机 / 眨眼 / 点头 / 睡觉」四个状态就够用。
5. 若想更贴 logo，可把 `public/mark.svg` 一起垫进去，强调「额头的金点 = logo 右下角金点」。
