## 用到的风格（对应 341 条提示词）

- **M6 苹果发布会风**：深墨舞台、玻璃产品框、镜头持续移动、产品先于文案出现；把原提示词的“白 + 亮蓝”换成了师说的“墨绿 + 薄荷 + 奶油纸”，避免和品牌打架。
- **M7 极简卡点**：一个镜头只讲一件事；大量留白；单一强调色（问题段用陶土红，解决段用玉绿）；文字用遮罩显出来；不弹跳、不闪、不堆粒子。
- **L33 瑞士动态排版**：数据页的 6 列网格、极端的字号对比、一条信号色、左对齐的理性排版。
- **A3 大字冲击**：没人回 / 不敢信 / 怕打扰，三个词跟着 96 BPM 的拍子砸进画面。
- **E1 极简几何**：夜晚空镜的圆环、全片的 72px 网格与极细线。
- **L13 数据实体化**：教师端的 FAQ 不是数字，是一摞真的纸卡；一张一张叠上去，撤回时再抽走一张。
- **L43 活体实机录屏**：学生端 / 教师端 / 校园工具全部来自实际运行的演示账号，不是画的 mock。
- **L59 玻璃质感产品**：浏览器框、接力节点、安全面板都用磨砂玻璃与细边框，配柔和的顶部聚光。
- **Z / C1 中国风纸张**：奶油纸底、宋体大字、金色印章；让“苹果式发布会”落在师说的纸墨气质上，而不是变成另一个 Apple 仿制品。

## 重新生成

依赖：Node 24、Python 3.12、ffmpeg、Microsoft Edge、`edge-tts`、`numpy`、`Pillow`。

```bash
# 1. 启动师说开发环境（API 8787 + Vite 5200）
npm run dev

# 2. 抓取长版需要的界面（ask-file / 洞察 / 食堂 / 管理端 / 登录页）
node promo/keynote/capture.mjs
node promo/keynote/capture-file.mjs

# 3. 旁白与时间轴
python promo/keynote/build_vo.py

# 4. 96 BPM 配乐（读取 timeline.json）
python promo/keynote/build_music.py

# 5. 混音
ffmpeg -y -i promo/keynote/audio/vo_master.wav -i promo/keynote/audio/music.wav \
  -filter_complex "[1:a]volume=1.4,atrim=0:150.28[m];[0:a]aformat=channel_layouts=stereo[v];[v][m]amix=inputs=2:duration=longest:normalize=0,loudnorm=I=-16:TP=-1.5:LRA=9" \
  -ar 48000 -ac 2 -t 150.28 promo/keynote/audio/final_audio.wav

# 6. 静态服务 + 逐帧渲染
python -m http.server 5301 --bind 127.0.0.1
node promo/keynote/render.mjs

# 7. 编码
ffmpeg -y -framerate 30 -i promo/keynote/frames/f_%05d.jpg -i promo/keynote/audio/final_audio.wav \
  -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -profile:v high -level 4.1 \
  -c:a aac -b:a 192k -ar 48000 -t 150.28 -movflags +faststart -shortest \
  "promo/师说宣传片_长版_1080p.mp4"

# 8. 字幕
python promo/keynote/build_srt.py
```

`timeline.json` 是唯一时间基准：旁白、字幕、配乐和画面都从它读取。重新生成配音后时长会有轻微变化，画面会自动适配。

| `audio/` | 旁白分句、配乐、混音母版 |
