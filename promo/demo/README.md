# 师说 · 功能演示视频（6 分 15 秒）

## 画面做法

- 真实界面截图放在 1440×900 浏览器视口内，右侧 368px 讲解栏同步显示当前旁白与 9 段进度。
- 光标、点击涟漪、输入文字、绿色/橙色高亮框、镜头推拉全部由 `window.__render(t)` 按时间确定性渲染，30fps 逐帧截图。
- 高频截图为 2880×1800，缩放后仍保留界面细节；输入框会先用同色底遮住占位符，再逐字输入。
- 旧食堂截图顶部的计数是 103 档口 / 3,173 道菜，与旁白 107 / 3,758 冲突，因此这一段改用「真实图书馆馆藏页 + 食堂数据浮层」呈现，不再直接展示旧截图；浮层里的档口、菜品数字与旁白一致。
- 片尾二维码来自 `promo/full/assets/qr-intro.png`。

## 重新生成

```bash
# 1. 旁白、时间轴、SRT
python promo/demo/build_vo.py

# 2. 配乐与混音
python promo/demo/build_music.py

# 3. 预览关键帧（可选）
node promo/demo/preview.mjs 35 292 367

# 4. 8 进程逐帧渲染 + 1080p 封装
node promo/demo/render_parallel.mjs

# 5. 720p
ffmpeg -y -i promo/师说功能演示_1080p.mp4 \
  -vf "scale=1280:720:flags=lanczos" \
  -c:v libx264 -preset slow -crf 20 -pix_fmt yuv420p \
  -c:a aac -b:a 128k -ar 48000 -movflags +faststart \
  promo/师说功能演示_720p.mp4
```
