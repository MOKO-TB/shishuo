## 重新生成

依赖：Node 24、Python 3.12、ffmpeg、Microsoft Edge、`edge-tts`、`numpy`、`Pillow`。

```bash
# 1. 启动师说开发环境（API 8787 + Vite 5200）
npm run dev

# 2. 抓取新增功能素材
node promo/full/capture.mjs
node promo/full/capture-tools.mjs
node promo/full/capture-analog.mjs

# 3. 女声旁白与时间轴
python promo/full/build_vo.py

# 4. 96 BPM 配乐（读取 timeline.json）
python promo/full/build_music.py

# 5. 混音
ffmpeg -y -i promo/full/audio/vo_master.wav -i promo/full/audio/music.wav \
  -filter_complex "[1:a]volume=1.35,atrim=0:311.236[m];[0:a]aformat=channel_layouts=stereo[v];[v][m]amix=inputs=2:duration=longest:normalize=0,loudnorm=I=-16:TP=-1.5:LRA=9" \
  -ar 48000 -ac 2 -t 311.236 promo/full/audio/final_audio.wav

# 6. 静态服务 + 逐帧渲染（建议分两段）
python -m http.server 5302 --bind 127.0.0.1
node promo/full/render.mjs 0 4700
node promo/full/render.mjs 4700 9338

# 7. 编码
ffmpeg -y -framerate 30 -i promo/full/frames/f_%05d.jpg -i promo/full/audio/final_audio.wav \
  -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -profile:v high -level 4.2 \
  -c:a aac -b:a 192k -ar 48000 -t 311.236 -movflags +faststart -shortest \
  "promo/师说宣传片_完整版_1080p.mp4"

# 8. 字幕
python promo/full/build_srt.py
```

`timeline.json` 是唯一时间基准：旁白、字幕、配乐和画面都从它读取。重新生成配音后时长会有轻微变化，画面会自动适配。
