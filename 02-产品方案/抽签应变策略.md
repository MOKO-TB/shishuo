## 2. 优先级与弹药包

### 主攻 65%：③ 师生答疑互助平台
方案见《产品方案-知了.md》。赛前准备：FAQ 种子语料、置信度策略、教师端交互稿。

### 强备选 20%：⑥ 灾害应急知识智能问答 Agent（同技术栈，换语料即可）
- 打法：把"知识库"换成权威应急指南（地震/火灾/溺水/触电/煤气泄漏官方科普），检索后输出**分步骤操作指引**；强语音交互（浏览器 Web Speech API 即可）。
- 亮点设计：无网环境提示卡、"紧急模式"大字版界面、模拟场景演练模式。
- 赛前准备：应急知识问答语料 200 条、语音交互技术验证。
- 与主攻共用 90% 底座，抽到不慌。

### 稳备选 10%：② 闲置流转与租赁平台
- 打法：团队做过 shiwu-market（Vue3+FastAPI 二手交易+AI 估价），**经验直接迁移，代码不搬**：校内认证、以物易物、按天租赁角是命题新增点，AI 做估价与文案生成。
- 风险：交易类功能面广（鉴权、状态机、图片上传），100 小时内做完压力大，故列为稳备选而非主攻。

### 轻量预案 5%：① 食堂随机决策器 / ④ 旧衣回收点查询工具
- 两者本质是"数据录入 + 推荐/地图 + 轻社交"，体量小，抽到反而轻松；AI 亮点用"口味画像推荐 / 回收知识问答"保住"AI 融合"得分项。赛前只准备这两页纸的方案梗概。

### 高风险：⑤ 守护回家路 · 老人防走失安全网
- 涉及地图围栏、定位、扫码上报的硬件式联动，Web 端 100 小时完成度风险最高。真抽到：砍到"二维码联系卡 + 管理端地图打点 + 上报通知"，地理围栏用简化半径判断。

## 3. 开赛抽签后 30 分钟决策流程

1. **0–5 分钟**：确认抽中命题，翻开对应弹药包，全队对齐 MVP 范围（先砍再说）。
2. **5–15 分钟**：定数据模型（5–8 张表）与 API 清单（10–15 个接口），写进共享文档当"合同"。
3. **15–25 分钟**：仓库初始化、前后端骨架、部署管线跑通空壳上线。
4. **25–30 分钟**：按《100小时作战计划》挂上里程碑，各自认领模块。

> 原则：抽到任何命题都不改技术栈、不改分工、不推翻底座——变的只是领域模型和语料。
