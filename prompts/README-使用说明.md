# Zcode 提示词 · 使用说明

**这三个文件不是让你发给 Zcode 的，是让你按顺序复制粘贴（或 @ 引用）的。**

| 顺序 | 文件 | 什么时候用 | 期望产出 |
|---|---|---|---|
| 0 | `资料包-三场景可引用事实.md` | **先看，不是发给模型的独占文档** | 唯一允许引用的事实库（L/W/Z 编号） |
| 1 | `P1-痛点挖掘.md` | 先跑，新会话。**必须连资料包一起贴** | 三个官方场景内各 4 条痛点（带类型与来源编号）+ 两段判断 |
| 2 | `P2-方向生成.md` | 把 P1 结果贴进来，再贴这个 | 5 个方向（含"相对官方方案的增量"/野心版/100h 切片/评分预演）+ 队长立场 |
| 3 | `P3-收敛方案.md` | 选定方向后，新会话 | MVP 边界、选型、100h 排期、演示分镜、风险清单 |

**必须新开会话。** 三段一锅端会退化成只做完 P1。

**P1 必须和资料包一起贴**，否则它会自己编数据。这是本套提示词里最容易被忽略、后果最严重的一步——编出来的百分比在路演时被评委问一句"这个数据哪来的"就完了。

## 命题范围（理解这一点再动手）

OP2 官方给了三个方向，各自带一个方案：

| 场景 | 官方及格线方案 |
|---|---|
| 旧衣回收 | 回收点查询工具（位置 + 去向说明） |
| 老人走失 | 防走失安全网（二维码联系卡 + 定位围栏 + 路人扫码，事前-事中-事后闭环） |
| 灾害应急 | 应急知识问答 Agent（自然语言问，分步指引，支持语音） |

**在这三个场景里做，不发散到别的领域。** 但要清楚：这三条是**方案**，不是痛点，而且评委心里已经有这个默认答案。所以：

- P1 是拿这些方案当"已知解"，倒推它们**还漏掉的人、还漏掉的环节**；
- P2 每个方向必须写出"相对官方示例多做到什么"，否则 17 分的原创性拿不到。

原样复刻任何一个官方方案，等于 0 增量。

## 怎么送进去

- **粘贴文本**：最稳。直接复制文件正文进对话框。
- **@ 文件引用**：Zcode 能读工作区文件的话，把 `zcode-prompts` 整个文件夹放进项目根目录，然后 `@P1-痛点挖掘.md` + 一句"只执行本文件内容，不要往下做 P2"。
- **别做的事**：三个文件一次性全 @，或把这份说明也一起发过去。关于"你怎么用"的话对它全是噪音。

## GLM-5.3-Flash 的几个坑

- **字数上限别删。** 无上限时它会写得很长很空，卡住字数反而更实。
- **只输出 3 个方向就停了**：回"继续，从第 4 个开始，格式同上"，不要重开会话。
- **偷偷用"学生做不出来"当理由**：回"按野心条款，这个理由无效，请用四类允许理由重新判断"。
- **P1 全是 C/D 级证据**：说明它在编。回"只保留 A 级的，其余重写"。
- **温度**：如果 Zcode 能调，P2 创意阶段 0.9，P3 收敛阶段 0.3。

## 痛点颗粒度校准

P1 最容易崩的是颗粒度。这是"合格 vs 不合格"对照，可以拿去纠正它：

| 不合格（太粗，推不出功能） | 合格（能直接指向功能） |
|---|---|
| 学生复习效率低 | 期末周在三四个群里翻聊天记录找老师发的复习范围，翻 20 分钟找不到，最后问同学要截图 |
| 老人容易走失 | 老人出门买菜两小时没回，家属沿路问人、发朋友圈，找人的前两小时全靠运气 |
| 校园信息分散 | 社团活动改时间只发在公众号推文里，报名的人不知道，到场发现改了，白跑一趟 |
| 办事流程复杂 | 补办学生证要跑三个窗口、盖两个章，其中一个只在周二上午开，第一次去的人都白跑 |

差别：合格的描述里有**具体的人、具体的时间点、具体的动作、具体的损失**，它天然能推出功能长什么样；不合格的只能推出一句"做个平台"。

## 判断产出好不好的三个信号

1. **P1 出来的痛点能不能互相串起来**（都在说同一类结构问题）——能，说明它真的在观察；不能，说明它在凑数。
2. **P2 的方向里有没有一个让你觉得"这个以前做不起"** ——没有，说明野心条款没生效，退回重跑。
3. **评分预演表的合计分有没有超过 85** ——全都 88、92 说明它在讨你开心，让它把"完成度"和"代码质量"这两项按最坏情况重打。
