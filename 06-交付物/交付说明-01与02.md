### 运行方式（无需 npm install）

要求 **Node.js 24+**。

- Windows：解压后双击 `启动-师说.bat`，浏览器自动打开 <http://127.0.0.1:8787/>
- macOS / Linux：`sh start.sh`
- Docker：`docker compose up --build`

首次启动自动建库、建演示账号。AI Key 未内置；需要 AI 作答时在 `/admin/` →「AI 用量」
填任意兼容 OpenAI 的 Key，或在 `.env` 填 `AI_API_KEY`。不配 Key 时课程检索、拒答、
转教师、教师回复与 FAQ 沉淀闭环仍可完整演示。

## 五、评审前如有新提交，如何刷新交付包

工作区还在继续迭代时，在仓库根目录执行一条命令即可重新生成两个包与校验值：

```bash
python -I dev/build-delivery.py
```

脚本会自动：构建前端 → 按当前工作区打包 → 生成 UTF-8 文件名的 zip → 重算 `SHA256SUMS.txt`。
若只想用现有 `dist/` 快速重打（不再构建），加 `--skip-build`。
