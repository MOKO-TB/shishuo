# 师说 · 路演演示

苹果发布会风格的 12 页路演 deck。主用动态网页版；PDF 与 PPTX 是提交/兜底版本。

## 交付物

| 文件 | 用途 |
|---|---|
| `index.html` | **动态演示版**（主用）。浏览器全屏播放，逐页分步动画、键盘/翻页器控制 |
| `师说路演.pdf` | 13 页静态版，16:9，用于提交、邮件、现场 PDF 备份 |
| `师说路演_静态版.pptx` | 13 页图片版，带**演讲备注**（每页 20–40 秒的口播稿），用于必须交 PPT 的场合 |

> PPTX 是逐页图片 + 演讲备注，**不能在 PowerPoint 里直接改字**。改文案请改 `index.html` 后重新导出。

## 怎么放

1. 用 **Chrome / Edge** 打开 `index.html`（不要用 IE）。
2. 按 `F` 全屏，`→` / 空格 按节奏推进；一页可以有多拍，讲完再按。
3. 现场演示时按 `B` 黑屏，把注意力交给产品；再按恢复。
4. 计时器 `T`，帮助 `?`，回封面 `R`，Home / End 首末页。
5. 点击舞台右侧翻页，左侧 16% 区域回退；支持触屏左右滑。
6. 地址栏加 `#3` 可直接跳到第 3 页（刷新后生效）。

### 键盘

| 按键 | 动作 |
|---|---|
| `→` / `↓` / `PageDown` / 空格 / Enter | 下一拍；本页拍完则下一页 |
| `Shift + →` | 跳过本页剩余拍，直接下一页 |
| `←` / `↑` / `PageUp` / Backspace | 回退一拍 |
| `Shift + ←` | 直接上一页 |
| `F` | 全屏 |
| `B` | 黑屏 |
| `T` | 显示/隐藏计时器（第一次翻页开始计时） |
| `?` / `/` | 帮助 |
| `R` | 回封面 |

## 12 页结构

1. 封面：师说 / 让每个课后问题，都有回响
2. 痛点：21:47 的问题，等到 08:31
3. 主张：把老师的答案，变成 AI 的第一反应
4. 产品：打开就能问（文字/语音/拍题/文档）
5. 引擎：检索 → 置信度 → AI 带出处答 / 转老师 → FAQ 回流
6. 学生端：整份作业、33 位导师、学科工具、语音、复习卡
7. 教师端：5 个同题 → 1 条回复 → 1 条 FAQ
8. 校园：地图、食堂、学习通、校历、图书馆、73 条经验卡
9. 可信：出处、边界、权限、审计（9 个治理模块）
10. 实测：157/157、41/41、81、33、75、9、5
11. 路线：5 门课 → 学院级试点 → 企业 FAQ
12. 收尾：老师写下的每一句话，都成为 AI 的第一反应 + 二维码

## 重新生成

依赖：Node + `playwright-core`（用本机 Edge）、Python + `pymupdf` / `python-pptx` / `Pillow`。

```bash
cd "D:/100h/jiaoshi ai"

# 一键：截图 → PDF → 字体子集化 → PPTX
bash deck/tools/build_all.sh
```

分步：

```bash
node deck/tools/shoot.mjs        # 12 页终态 PNG → deck/preview/
node deck/tools/export.mjs       # → deck/师说路演.pdf（约 44MB）
python deck/tools/optimize_pdf.py # 字体子集化 → 约 12MB
python deck/tools/build_pptx.py  # 从 PDF 重建 → deck/师说路演_静态版.pptx
```

## 说明

- **字体**：`assets/fonts/` 里是 Noto Sans SC / Noto Serif SC 可变字体（约 42MB），保证任何电脑打开都是同一套字。只分享 PDF/PPTX 时不需要带字体。
- **图片**：`assets/img/` 是真实产品截图（学生端、教师端、管理端、校园工具），没有用生成图冒充界面。
- **无音频**：deck 本身静音，适合现场讲。需要配乐/旁白时，用 `promo/` 里已有的宣传片成片。
- **动画**：所有动效是 CSS/JS 手写，无外部依赖、无网络请求；断网也能放。
