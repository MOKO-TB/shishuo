# 技术栈与预研清单

> 性质说明：以下 5 个 spike 是**赛前练手与环境验证**，验证"我们会在赛时用这套技术"。spike 代码不进入赛时仓库；赛时 11/4 从空仓库重新开始（红线要求）。

## 1. 选型（已定，不再摇摆）

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 后端 | Python 3.12 + FastAPI | 团队熟（shiwu-market 同栈）；异步流式输出原生支持 |
| 前端 | Vue 3 + Vite + Tailwind CSS | 团队熟；移动端适配快 |
| 数据库 | SQLite（SQLAlchemy） | 零运维、备份=拷文件；演示规模足够 |
| 向量库 | ChromaDB（本地持久化） | 轻量、pip 即装 |
| 向量模型 | **bge-small-zh-v1.5** | 中文效果好、体积小；本地已有（`Desktop/黑客松项目想法/引路学长_向量模型包/`），**赛时自带拷贝**，现场不依赖网络下载 |
| LLM | 校园端点 / DeepSeek / Qwen / Kimi 多路配置 | 双供应商 + mock 三级降级 |
| 部署 | 云服务器或内网穿透（cpolar/ngrok）+ docker-compose | 开赛 2 小时内上线空壳 |

| # | Spike | 验收标准 |
